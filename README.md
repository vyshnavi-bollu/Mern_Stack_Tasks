# MERN Stack Task 1 – Product API

A simple REST API built using Node.js, Express.js, and MongoDB for managing product data.

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose

## Features
- Express Server Setup
- MongoDB Connection
- Product Model
- API Routes
- Environment Variables

## Run Project
npm install
node server.js
